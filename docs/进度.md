Codex 订阅到期时正在做下面这段，做到一半被断，可能有未提交的改动留在笔记本的工作区。接手时先在本地 `git status` 看一下，有半成品就检查后接着做完，没有就从头做：

1. 头像裁切吊牌换图时旧图缩小闪烁：AvatarCropper.tsx 里 DevelopingMedia 的尺寸和位置挂在外层容器、按最新图片的 size 计算，换图时旧图层被改了大小。要让每一层保持自己的几何，或裁切框内换图不保留旧图层。
2. 显影重复播放：DevelopingMedia 按 src 记录是否显影过，但头像、裁切预览、媒体每次都 createObjectURL 生成新地址，导致每次进入都重播。改成按稳定的 mediaKey（存储 key 加更新时间或哈希）判断，并按 mediaKey 复用 objectURL。
3. 会话票根抽屉卡顿：新增要等服务器返回才插入（改成先插临时票根）；删除和归档要先等请求（改成先播退场动画）；抽屉开合时背后聊天页用 filter: brightness 整页调暗（改成盖一层遮罩只做 opacity）；切换会话时消息层的 blur 关键帧（改成只用 opacity 和 transform）。
