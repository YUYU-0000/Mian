# 设置界面接入说明（给 Codex）

设计稿：`design-reference/设置界面维护中.html`。打开就能点，四个档案袋：字体、壁纸、语音、存储。

你的任务：把这张设计稿接进正式的 React 前端，并把页面里预留的接口接成真功能。

## 规则（先读）

- 外观照设计稿原样搬，不要重新设计，不要改文案（页面里的繁体字提示，例如「試聽失敗」「已導出」，原样保留）。
- 不要改已有的功能和已有的测试行为。
- 不要做防御性编程：不要到处加空值兜底、try/catch 套娃、类型再校验、备用方案。设计稿和下面写清楚的输入就是可信的输入。
- 不要反复对比、反复检查、反复验证。写完跑一次 `npm run typecheck` 和 `npm run build`，通过就结束。

## 1. 页面和入口

- 新建 `client/src/pages/Settings.tsx`，样式放进 `client/src/settings.css`（从设计稿里搬）。
- 在 `App.tsx` 加路由 `/settings`，跟 `/connections` 一样包一层 `ErrorBoundary`，用同样的 `navigateWithTransition` 过渡。
- 入口：主界面 `Home.tsx` 底部 dock 的第二个图标（`dock-2`，现在是空的 `Icon`）改成按钮，点击进入 `/settings`。dock 第一个图标继续进连接中心，不要动。

## 2. 预留接口

设计稿在 `<script>` 开头列了这几个全局函数，页面只负责调用。React 版里改成组件内的普通函数即可，不用挂在 `window` 上。

### goBack()

左上角返回，回主界面：`navigateWithTransition("/")`。

### 壁纸

设计稿已经会把上传的图片 / 视频存进浏览器的 IndexedDB，这部分照搬。另外要做的只有一件事：主界面 `Home` 用这张壁纸当背景。

### 字体：saveFontStyle(page) / testFontStyle(page)

字体页可以左右滑动、增删多页，每一页是一套字体方案，字段：

- 名字：拍立得下面那个输入框（placeholder `UNNAMED`）
- FACE：一段 `@font-face { … }` CSS
- VIEW：预览文字
- SIZE：滑杆，12–18px，默认 16px

`saveFontStyle(page)`：把这一页的 FACE 塞进页面 `<head>` 里的一个 `<style>`，把这套字体设成聊天气泡用的字体（用 CSS 变量，例如 `--chat-font-family`、`--chat-font-size`），并存进 `localStorage`（键名 `mian_font_profiles`，存全部页面和当前选中的是哪一页）。下次打开时读出来并生效。

`testFontStyle(page)`：只把这套字体临时套在这一页的 VIEW 预览文字上，不保存，不影响聊天界面。

### 语音：testVoice(cfg)

`cfg = { apiKey, voiceId, model, text }`，对应语音页票根上的 TOKEN、VOICE、MODEL 三栏和试听文字。

- 后端新加 `POST /api/voice/test`，接收 cfg，调用 ElevenLabs：
  `POST https://api.elevenlabs.io/v1/text-to-speech/{voiceId}`，请求头 `xi-api-key: {apiKey}`，body `{ "text": text, "model_id": model }`，返回 `audio/mpeg`，原样转给前端。
- 前端拿到音频直接播放，播完 resolve；请求失败就 reject（设计稿会自己弹「試聽失敗」）。
- 语音页也能增删多页，每页一套配置，连同备注一起存进 `localStorage`（键名 `mian_voice_profiles`）。

### 存储：exportData() / importData(file)

`exportData()`：生成一个 JSON 文件让浏览器下载，文件名 `mian-backup-YYYYMMDD.json`，内容：

- 全部对话（从后端读）
- 字体方案 `mian_font_profiles`
- 语音配置 `mian_voice_profiles`，但不要导出 apiKey

`importData(file)`：读这个 JSON，字体和语音配置写回 `localStorage`；对话通过后端新加的 `POST /api/import` 写回，id 相同的以导入的为准。完成后 resolve，失败 reject（设计稿会自己弹提示）。

壁纸不导出。

## 3. 完成标准

- 从主界面 dock 第二个图标能进设置页，左上角能返回。
- 四个档案袋外观和动画跟设计稿一致。
- 字体能保存并在聊天界面生效；语音能试听出声；导出能下载 JSON，导入能恢复。
- `npm run typecheck`、`npm run build` 通过。
